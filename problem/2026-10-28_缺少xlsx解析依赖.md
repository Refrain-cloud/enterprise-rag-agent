# 缺少 openpyxl，无法解析 xlsx

- 日期：2026-10-28
- 状态：已解决
- 影响范围：5 个 xlsx（预算执行、费用台账、员工花名册、工时统计）

## 现象

`import openpyxl` 报 `ModuleNotFoundError: No module named 'openpyxl'`；pandas 3.0.3 读取 xlsx 也依赖该库。

## 原因

当前 Python 3.14 环境未安装 openpyxl。

## 解决方案

执行 `python -m pip install openpyxl`（实际安装 3.1.5），并写入 `requirements.txt`。

## 验证结果

`python -m src.ingest.build_corpus` 成功解析全部 5 个 xlsx，覆盖率报告 `xlsx` 计数为 5，无解析错误。读取时 openpyxl 会输出 `UserWarning: Workbook contains no default style`，属无害警告。

## 参考

pandas 文档：读取 Excel 需要 openpyxl（xlsx）或 xlrd（xls）。
