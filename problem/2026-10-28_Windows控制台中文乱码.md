# Windows 控制台中文输出乱码

- 日期：2026-10-28
- 状态：已解决
- 影响范围：本地调试脚本输出、docx 内容预览

## 现象

用 Python 读取中文 docx / manifest 并 print 时，终端显示乱码（中文路径与正文无法阅读）。

## 原因

Windows 控制台使用 GBK/CP936 代码页，Python stdout 默认不是 UTF-8。

## 解决方案

运行脚本前设置 `PYTHONIOENCODING=utf-8`；写文件时显式使用 `encoding="utf-8"`。

## 验证结果

设置后中文正常输出，manifest 统计与 docx 预览可正常阅读。
