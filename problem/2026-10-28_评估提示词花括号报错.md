# 评估提示词中的 JSON 示例导致 str.format 报 KeyError

- 日期：2026-10-28
- 状态：已解决
- 影响范围：`eval/run_eval.py` 的 LLM 评委

## 现象

首次运行 `python -m eval.run_eval` 时，在第 1 题调用 `judge()` 处抛出：

```
KeyError: '"score"'
```

## 原因

`JUDGE_PROMPT` 中直接写入了 JSON 输出示例 `{"score": 0, ...}`，随后用 `str.format()` 填充问题、答案等字段。`str.format()` 会把 JSON 示例里的 `{...}` 也当作占位符解析，于是把 `"score"` 当成字段名查表失败。

## 解决方案

在提示词模板中把作为字面量的花括号转义为双花括号：

```python
{{"score": 0, "faithful": true, "refusal_ok": true, "permission_ok": true, "reason": "..."}}
```

`str.format()` 渲染后恢复为单花括号，模型看到的仍是合法 JSON 示例。

## 备选方案

使用 `string.Template`（`$question` 占位）或 `replace()` 拼接，可彻底避免与 JSON 花括号冲突；当前模板字段少，选择最小改动的转义方案。

## 验证结果

重新运行评估，第 1 题正常进入评分流程，不再抛错。
