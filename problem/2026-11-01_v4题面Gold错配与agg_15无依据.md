# 【面试可讲】评估集自身也会错：题面没问、Gold 没依据、judge 被假设句骗过

- 日期：2026-11-01
- 状态：已解决（`fact_24`、`ver_17` 为已知生成漂移）

## 现象

修复 `ver_16` 后，120 题全量（judge×1）出现 8 道 1 分。逐题复判与重复生成后分三类：

1. **judge×1 噪声（3 道）**：`multi_02`、`fact_23`、`agg_11`。复用原回答复判三轮均为 2 分，问题在判分抽取而不是答案。
2. **题面与 Gold 错配（2 道）**：
   - `ver_18` 题面只问“P6 以上一线城市住宿标准”，Gold 还要求二线 600 元/晚、其他城市 450 元/晚、餐补 150 元/天；
   - `chat_05` 题面只问“为什么选 A 家”，Gold 还要求“走 5,000 元以上审批”。
3. **Gold 与原文冲突（1 道）**：
   - `agg_15` Gold 写“恢复耗时逐月上升，原因是数据量增长”，但唯一 Gold 文档 `PT-002` 只有三行耗时记录，全文没有“数据量”也没有“增长”。
4. **生成漂移（2 道）**：`fact_24`、`ver_17`。同一提示词多轮重跑，分别 2/3、1/3 轮次通过。

## 原因

- 出题时把“想考的知识点”写进 Gold，题面只覆盖了其中一部分；旧基线单次生成恰好答全，掩盖了错配。
- `agg_15` 的“数据量增长”不是原文事实，是出题时的推断；旧回答用“若日增数据量上升……亦可能导致”的假设句，judge 判为 covered，说明语义匹配对“若……可能……”这类推断偏宽。
- `temperature=0 + seed` 下生成仍不可复现，单次全量会出现几道偶发漏写。

## 解决方案

- `ver_18` 题面扩为“住宿标准（一线、二线、其他城市）和餐补……分别是多少？”，Gold 不变（`HR-006` 原文支持全部数值）。
- `chat_05` 题面补“选 A 家后还需要走什么审批流程？”，Gold 不变（`IM-016` 原文有“走 5000 以上审批，找张总”）。
- `agg_15` 题面改为“资料是否说明了耗时上升的原因？”，Gold 与 key_facts 改为“资料未说明耗时上升的原因”，把缺陷题转成“不臆造原因”的忠实性测试。
- `fact_24`、`ver_17` 不改题，保留单次基线结果并在交接文档标注为漂移题。
- 全程未放宽任何有原文依据的 Gold，`data/` 未修改。

## 验证结果

| 项 | 结果 |
|---|---|
| `ver_18` / `chat_05` / `agg_15` 重跑（judge×3） | 均为 2 分 |
| 合并基线 `report_v4_gen4` | 118/120 = **1.9833**，MRR 0.8471 |
| 检索 Recall / Gold 覆盖率 / 引用 / 忠实 / 拒答 / 权限 | 1.000 |
| 非满分题 | `fact_24`、`ver_17`（均为已知漂移） |
| 单次全量原始结果（judge×1） | 112/120 = 1.9333 |

## 结论

评估集的 Gold 本身也会错，且错配会被“单次生成恰好答全”掩盖。发现后应回原文核实：题面没问的扩题面，原文不支持的改 Gold；不应通过放宽 judge 或反复重跑直到通过。
