# 【面试可讲】日期幻觉：模型把训练时间当成“现在”

亮点：一道版本冲突题从 0 分到 2 分，根因不在检索也不在 judge，而是系统提示词没有告诉模型“今天几号”；模型据此臆测当前年份，误判新制度未生效。

- 日期：2026-10-29
- 状态：已解决

## 现象

- 30 题评估中，`ver_02`（P6 及以上北京出差住宿标准，以哪份文件为准）得 0。
- 模型称“当前为 2024/2025 年”，据此判断《费用报销制度（2026 年修订版）》（`FN-012`）尚未生效，转而只依据旧标准；标准答案要求 800 元/晚，并以 `HR-004` 与 `FN-012` 为准。
- 同一题独立重跑曾得到 2 分，表现为偶发——因为模型在不知道当天日期时自行推断，推断结果不稳定。

## 原因

- `SYSTEM_PROMPT` 只包含回答规则，没有注入当前日期。模型只能从训练语料和资料中的日期猜测“现在”，倾向把当前时间锚定在训练截止时间附近。
- 版本判定规则本身正确（active + 生效日期 + 非草稿），但缺少正确的“现在”，规则无法落地。

## 解决方案

- `src/agent/ask.py` 新增 `_system_prompt()`：每次调用时用 `date.today().isoformat()` 注入“今天的日期是 YYYY-MM-DD”，并明确“判断文件是否已生效、是否为现行版本时一律以该日期为准，不要假设当前年份”。
- 不硬编码日期，由运行时生成。

## 验证结果

- 单题冒烟：`ver_02` 输出“截至 2026-10-29”，判定 800 元/晚、`MS-006` 为未发布批注稿，未再出现年份臆测。
- 全量 30 题（qwen-plus judge）：仅 `ver_02` 由 0 → 2，其余 29 题逐项得分、路由与引用完全不变；平均答案得分 1.933 → 2.000，Recall@8 1.000、MRR 0.789、引用率 1.000、拒答正确率 1.0、权限合规 1.0 / 0 泄漏、路由 26 rag / 4 sql 均不变。
