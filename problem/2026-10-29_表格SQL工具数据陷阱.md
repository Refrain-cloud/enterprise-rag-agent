# 【面试可讲】表格统计从“模型心算”改为“数据库计算”

亮点：同样一道统计题，把答案正确性从“依赖模型逐行心算”变成“SQL 计算 + 模型只转述”，并系统性处理了标题行、合计行、千分位、百分比、多 sheet 五类真实数据陷阱。

- 日期：2026-10-29
- 状态：已解决

## 现象

1. MVP-0 基线中，结构化聚合问题由大模型直接读表格文本计算。`agg_04`（已付款单据笔数与金额）出现过笔数口误，金额正确；说明逐行计数不可靠。
2. 直接用 pandas 读取原始文件也不可靠：
   - `LG-001` CSV 前两行是标题行和空行，表头在第 3 行；金额带千分位（`"4,280"`）。
   - `BG-001`、`MS-009`、`XS-001`、`XS-003` 末尾有“合计/小计”行。SUM/COUNT 会把汇总行重复计入；按“缺口”降序取最大会错选“合计”。
   - `BG-001`/`XS-001` 的执行率是百分比字符串（`"77.5%"`），无法直接求和或比较。
   - `XS-001` 是多 sheet 工作簿，其中“说明”页不是表格，但含问题需要的原因描述。

## 原因

表格文件没有统一结构：标题行、空行、汇总行、单位符号和多 sheet 混在同一份知识库里。把整张表当纯文本交给模型，等于让模型同时做“结构识别 + 数值清洗 + 算术”，任何一步出错都会污染答案。CLAUDE.md 核心原则 5 也要求统计类问题走 SQL/pandas。

## 解决方案

1. **表头检测**：去掉全空行后，在前 10 行中选非空单元格最多的一行作为表头（并列取最早），要求至少 2 列且宽度不低于后续 3 行的 60%；表头之前的行转为备注。
2. **汇总行拆表**：首列匹配“合计/小计/总计/汇总”的行拆到 `<表>_summary`，明细表保持干净。这样明细 SUM/COUNT/MAX 不会重复计算，“整体执行率”仍可查汇总表。
3. **数值清洗**：去掉千分位、货币符号和空格，支持括号负数；带 `%` 的列按百分点存为 REAL（77.5 表示 77.5%），空值写 NULL；非数值列保持 TEXT。
4. **多 sheet 处理**：每个 sheet 单独建表（ASCII 表名 + 图例映射 doc_id/sheet）；非表格 sheet 的文本进入提示词备注。
5. **SQL 沙箱**：内存 SQLite，`PRAGMA query_only=ON` + `set_authorizer` 只放行 SELECT/READ/FUNCTION/RECURSIVE，拒绝写操作、DDL、ATTACH、PRAGMA 与系统表；SQL 先校验单条 SELECT、无注释，执行带超时与行数上限。
6. **规则路由**：检索命中 CSV/XLSX 且问题含聚合关键词时走工具；两步 LLM（生成 SQL → 原样转述结果并标 `[doc_id]`）。失败自动回退原问答路径。
7. **权限复核**：工具按 doc_id 回查语料并再次执行 `can_access`，不依赖检索层传入的结果。

## 验证结果

- 本地 SQL 校验（不经模型）：agg_01 9530、agg_04 10 笔/32870、agg_03 实施交付部 4、agg_02 汇总 75.6% / 实施 CC-IM 81.1%，均与 gold 一致。
- 沙箱：DELETE、ATTACH、PRAGMA、多语句、注释、`sqlite_master` 查询均被拒绝。
- 权限：普通员工提问全量表（XS-003，confidential）时 `route=rag`，未载入机密表，无泄漏。
- 端到端：4 道结构化聚合题均 `route=sql`；agg_02 在补充“多小问要查明细 + 返回最高值”提示后完整答出三个要点。
- 全量评估指标见 `docs/handoff/2026-10-29_表格SQL工具.md`。

## 路由回归与修复（由评估暴露）

- **现象**：首版聚合关键词包含泛化的“多少”“几个”，30 题中有 8 题走 SQL。`ver_02`（住宿标准是多少、以哪份文件为准）和 `ver_04`（现行版本、账期多少天）因此绕过版本推理，直接查表作答，均得 0 分；引用率从 0.963 掉到 0.852。
- **原因**：“多少”是通用疑问词，不等于聚合意图；版本权威性问题需要结合状态、生效日期和废止声明判断，不能只做表内统计。
- **解决**：去掉“多少”“几个”，只保留强聚合词（合计/总计/几笔/最高/最低/最多/最少/平均/统计/汇总/占比等）；对含“以哪份文件为准”“现行版本”“哪一版”“最新版”“是否废止”等版本标记的问题禁用 SQL 路由。
- **验证**：重跑 30 题，SQL 恰好命中 4 道聚合题；引用率回到 1.000；4 道聚合题全部满分；`ver_02`/`ver_04` 回到 rag 并重新引用 gold 文档。
