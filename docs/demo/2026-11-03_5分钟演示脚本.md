- 演示环境：本地 `uvicorn`，浏览器打开 `http://127.0.0.1:8000`；Docker 启动方式见 README。
- 对应基线：开发集 121 题 **1.942**、留出集 20 题 **1.85**、单测 84 个、回答指纹 `ad595828258abf82`。
- 彩排状态：2026-11-03 已在真实浏览器完成全流程彩排（含拒答横幅、角色切换、SQL 路由、多轮）。

## 演示前检查（提前 10 分钟）

```bash
set -a; source .env; set +a
PYTHONIOENCODING=utf-8 python -m uvicorn src.api.main:app --port 8000
curl -s http://127.0.0.1:8000/api/health   # 必须 index_ready: true
```

- 浏览器缩放 100%，隐藏书签栏与侧边栏，关闭通知/聊天软件，开启勿扰模式。
- 页面点「新会话」，角色选「普通员工」，「显示节点轨迹」保持关闭。

- 兜底录屏**尚未录制**：演示前必须按文末方案录好并确认可播放；不要在直播中现场排查网络或代码。

## 分段台词

### 0:00–0:20 开场

「这是北辰智造的企业内部知识库 Agent，273 份文档，故意放了版本冲突、扫描件、权限密级等六类陷阱。项目不以能跑 demo 为标准，121 题开发集 1.942、20 题留出集 1.85。今天演示四件事：版本判定、权限在检索层、结构化问题走 SQL、多轮追问。」

### 0:20–1:35 扫描件与版本权威（`scan_03`）

问题：

> 2019 年版《差旅与报销标准》扫描件规定的一线城市住宿上限、餐补和报销时限分别是多少？2024 年修订版中 P4-P5/M1 职级对应的这三项标准分别是多少？

预期：2019 年版 450 元/晚、60 元/天、15 个工作日；2024 年版 650 元/晚、120 元/天、10 个工作日。来源包含 `SC-005`（superseded）与 `HR-004`（active）。

讲解点：

- 「旧版数值只存在于扫描件里，先过 OCR 才能检索；回答同时给出两版，而不是把旧版当现行标准。」
- 「判定依据是状态、生效日期和正文废止声明一起看，不盲信文件标题。」
- 展开「来源」：`SC-005` 标 superseded，`HR-004` 标 active；点击 `[HR-004]` 可定位来源卡片。

### 1:35–2:15 重复文档的权威版本（`ver_11`）

问题：

> 公司有两份内容相同的《报销流程》，一份标记为已过期、一份为 active，应以哪份为准？每月几号打款？

预期：以 `MS-008` 为准，`MS-007`/`MS-007C` 为 outdated，每月 25 日打款。

讲解点：

- 「两份文件内容几乎一样，靠元数据状态区分；回答明确说旧版不得作为现行依据。」
- 「如果时间紧，这段可压缩到 20 秒，只展示答案和来源状态。」

### 2:15–3:15 权限边界：同题换角色（`perm_06`）

第一步，角色「普通员工」：

> 2026 年 9 月全量报销台账里，已付款单据合计多少钱？

预期：红色拒答横幅「该信息属于公司机密，当前角色无权访问」，无来源。

第二步，切换角色为「财务」（切换会自动新开会话），重复同一问题。

预期：`route: sql`，答案 32,870 元，来源 `XS-003`。

讲解点：

- 「拒答不是靠提示词让模型别说，而是检索层按角色和密级过滤，机密文档根本没进上下文；所以连金额都不会出现在候选里。」
- 「财务角色下同一问题被识别为结构化聚合，走 SQL 而不是向量硬答，结果来自台账的 9 月工作表。」
- 「角色目前由调用方传入，是演示层；生产要接 SSO 和鉴权。」主动说明边界。

### 3:15–4:15 多轮追问（`mt_leave`）

角色切回「普通员工」，点「新会话」。可选：勾选「显示节点轨迹」。

第一轮：

> 员工满 3 年不满 5 年，年休假几天？

预期：10 天（工作日），引用 `HR-002`、`HR-023`。

第二轮：

> 那满 5 年不满 10 年呢？

预期：15 天，结合上一轮语境改写为独立查询。

讲解点：

- 「第二轮只有代词和省略，系统结合会话历史改写检索词；引用没有把上一轮的 HR 文档带错。」
- 「会话在应用层内存存储，图本身保持无状态，便于横向扩展和测试。」

## 兜底方案

**触发条件**：单个问题等待超过 40 秒、接口报错、关键数字答错、网络中断。满足任一条件就切录屏，不在直播中调试。

**录制方式**：

- OBS 或 Win+G，1920×1080、30fps，只捕获浏览器窗口；每段单独录，便于替换。
- 建议文件名（`build/` 已被忽略，不提交）：`build/demo/fallback_1_scan03.mp4`、`fallback_2_ver11.mp4`、`fallback_3_perm.mp4`、`fallback_4_multiturn.mp4`。
- 录完后备份到网盘；演示前确认能播放、有声音。

**降级顺序**：

1. 拒答横幅没出现：改用 `perm_04`（普通员工问「2026 年 10 月员工花名册中的研发总监是谁？」）→ 拒答；切 `HR` 同题 → 李维。该组合彩排可稳定触发。
2. SQL 路由失败：改讲 `perm_12`（管理层问 8 月收入/毛利率/应收）作为授权正例，不展示拒答对比。
3. 多轮改写失败：新开会话直接问「满 5 年不满 10 年年假几天」，然后口头说明多轮改写机制。
4. 模型接口整体不可用：直接播放完整兜底录屏，收尾时说明这是预录版本。

**禁止事项**：不展示 `.env`、API Key、终端历史；不现场改代码；不提「生产可用」；不碰 `agg_10`。

## 可能被问到

| 问题 | 一句话回答 |
|---|---|
| 为什么不让模型读全部文档？ | 权限过滤、版本冲突和上下文成本都不能只靠提示词解决。 |
| 为什么用 LangGraph？ | 显式状态机，路由和自检节点可观测、可测试；图不承载会话状态。 |
| 检索怎么做的？ | Chroma 向量 + BM25 + 元数据过滤，top-k 12；rerank 默认关闭，因为只提升 MRR、不提升答案且增加延迟。 |
| 权限怎么保证？ | 检索层按角色与密级过滤，guard 节点拦截越权最优命中，生成阶段拿不到机密内容。 |
| 最大的失败案例？ | `agg_10` 研发中心人数答错，是真实错误；`agg_13` 引用归属不符；judge 对复合事实点有假阴性。 |
| 还没做什么？ | 登录鉴权、分布式会话、可取消执行、生产级可观测性；当前是单机演示。 |
