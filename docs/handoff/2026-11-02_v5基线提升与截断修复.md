## 1. 900 token 截断修复

改动位置：`src/config.py:60-64`、`src/agent/ask.py:75-96`、`eval/run_eval.py:1200/1229-1233`。

- 新增 `_generate_complete()`：读取 `choices[0].finish_reason`，只有 `length` 才用同一消息、同一 seed 把预算翻倍重答（900 → 1800 → 2400）。
- 预算移到配置：`RAG_MAX_TOKENS`（900）、`RAG_MAX_TOKENS_HEADER`（1200）、`RAG_MAX_TOKENS_CEILING`（2400）。
- 结构化字段重写也走同一函数；首次生成截断时先补全再判字段违规。
- 结果记录 `generation_check.truncation`（每次预算与 `finish_reason`）和 `retried_on_truncation`。
- 全量中有 **8 题**触发重答：`fact_09`、`multi_04`、`ver_12`、`multi_08`、`multi_09`、`multi_11`、`multi_12`、`multi_13`；全部在 1800 `stop`，无仍截断。额外生成费用约 0.0498 元。

## 3. 拒答判定补漏

改动位置：`eval/run_eval.py:159-174`。

- `ref_06` 回答明确写“正文没有实施步骤与工期”“无法从现有资料中回答”，事实点全 covered，但 judge 的 `refused=false`，被判 0 分。

## 重要决策

- **截断只做定向重答，不全局抬高预算**：正常题行为与成本不变；命中截断的 8 题多付一次生成调用。
- **v5 独立版本，不回写 v4**：保持 v4 120 题历史基线可复现，v5 作为新增表格题的正式口径。
- **题面不完整时优先补问题，不砍 Gold**：`fact_15` 保留并发事实点，只把问题问全；补题面后必须检查 `route`，避免关键词路由误切。
- **拒答词表只加高精度短语，且只放在预期拒答路径**：`ABSENCE_REFUSAL_MARKERS` 仅在 `expect_refusal=true` 时参与判分。
- **生成漂移不“跑到过为止”**：`ver_17` 三轮 `[1,2,2]` 仍保留单次 1 分；`agg_11` 三轮 `[1,1,2]` 也不特殊处理。
- **合并基线混合了局部复判**：16 道拒答题与 `fact_15` 使用新 judge 指纹，其余行判定逻辑未变。

## 已知问题

1. **`ver_17` 单次漏写原目标**：三轮 2/3 轮写出“5 万”。若要让单次基线稳定，需要加提示词规则或改变问题问法；两者都会改变回答指纹，需重新全量。
2. **temperature=0 并不完全确定**：同一题重复生成会漂移；截断命中数从基线 2 题变为全量 8 题。单次基线应视为一次采样，稳定性用 `--gen-repeats` 观察。
3. **判分指纹混合**：16 道拒答题与 `fact_15` 使用新 judge 指纹，其余行是旧指纹；被改动的语义只影响 `expect_refusal` 路径。若要求全量指纹统一，需重判 121 题（约 0.7 元）。
4. **合并报告费用口径**：`results.jsonl` 中 16 行和 `fact_15` 的 usage 已替换，被替换掉的原始 judge 调用不计入报告的 1.3032 元；实际花费以 **1.66 元**为准。
5. **格式检测 18/102（仅观察）**：比 v4 的 26/102 少，来自生成措辞变化；自动重写仍关闭。
6. **表格题覆盖仍偏少**：121 题里只有 2 题走 table；`agg_16` 含“主要异常”按设计走 RAG。
7. **`--gen-repeats 3` 成本约为单次的 3 倍生成 + 3 倍判分**：只建议按 `--ids` 排查漂移。
8. **工作区仍有未跟踪文件**：`工作流程记录_2026-10-28_2026-10-29.md`、`工作流程记录_2026-10-30.md` 未入库，是否提交需确认。

## 运行/测试命令

```bash
# 日常 121 题（judge×1，单轮生成）
PYTHONIOENCODING=utf-8 python -m eval.run_eval --judge-repeats 1

# 出稿验收（judge×3）
PYTHONIOENCODING=utf-8 python -m eval.run_eval --judge-repeats 3

# 多轮生成（每轮判分，跨轮取众数；判分调用数 = gen × judge）
PYTHONIOENCODING=utf-8 python -m eval.run_eval --gen-repeats 3 --judge-repeats 1

# 预期拒答题离线复判（复用已存回答，不调用问答模型）
PYTHONIOENCODING=utf-8 python -m eval.run_eval --rejudge \
  --results build/eval/results.jsonl \
  --ids perm_02,perm_04,ref_01,ref_02,perm_06,perm_07,ref_04,ref_05,scan_08,perm_09,perm_11,perm_16,ref_06,ref_07,ref_08,ref_09 \
  --judge-repeats 1

# 把局部结果并入基线
PYTHONIOENCODING=utf-8 python -m eval.run_eval --merge-partial \
  --partial build/eval/results_rejudge.jsonl --results build/eval/results.jsonl \
  --ids perm_02,perm_04,ref_01,ref_02,perm_06,perm_07,ref_04,ref_05,scan_08,perm_09,perm_11,perm_16,ref_06,ref_07,ref_08,ref_09

# 从结果重建报告（不调用模型）
PYTHONIOENCODING=utf-8 python - <<'PY'
import json
from pathlib import Path
from eval.run_eval import _aggregate, _write_outputs
directory = Path("build/eval")
rows = [json.loads(line) for line in (directory / "results.jsonl").open(encoding="utf-8")]
report = _aggregate(rows, "eval/questions.v5.jsonl")
_write_outputs(report, directory, "report", "results.jsonl")
_write_outputs(report, directory, "report_v5", "results_v5.jsonl")
PY
```
