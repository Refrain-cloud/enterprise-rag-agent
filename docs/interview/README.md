# 面试故事集

这五个故事对应项目里真实发生的问题，每篇都能在 2–3 分钟内讲完。用法：

1. 先用每篇开头的**一句话版本**抛结论，别从背景讲起。
2. 讲清“现象 → 怎么定位 → 做了什么取舍 → 怎么验证”，数字只报和结论有关的。
3. 主动补一句边界或未解决项，面试官更愿意继续深挖。
