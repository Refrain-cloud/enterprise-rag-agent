北辰云 API 接口文档（摘要）

完整文档见开发者门户 dev.beichen-mfg.com。

认证

所有接口使用 Bearer Token，Token 有效期 2 小时，通过 /api/v3/auth/token 获取。

主要资源

资源方法路径
工单GET/api/v3/workorders
工单POST/api/v3/workorders
报工POST/api/v3/workorders/{id}/report
设备GET/api/v3/devices
设备数据GET/api/v3/devices/{id}/telemetry
物料GET/api/v3/materials

限流

单租户 600 次/分钟，超出返回 429。
