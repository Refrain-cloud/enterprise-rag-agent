结束今天的工作，完成与下一个新会话的交接。

1. 找到 `docs/handoff/` 下最新的一份交接文档（忽略 `README.md`，按日期和修改时间判断）。
2. 更新该文档的对应章节，不要追加流水账：
   - 当前进度：已完成 / 进行中 / 未开始
   - 今天的关键决策及原因（只写新增或变化的部分）
   - 遇到的问题及状态；技术问题同步到 `problem/YYYY-MM-DD_简短标题.md`，值得面试讲的标注【面试可讲】
   - 已知风险和待决事项
   - 明天开始的第一步，具体到文件或命令
   - 本次相关的提交号、测试或评估命令
3. 如果今天完成了一个完整模块，按 `CLAUDE.md` 新建当日交接文档；如果只是日终收尾，更新现有文档即可。
4. 检查 `git status`，提交代码和文档，使用 `feat:` / `fix:` / `eval:` / `docs:` / `chore:` 前缀。不要提交 `build/`、`.env`、密钥或 `.claude/settings.local.json`。
5. 最后用 3–5 行总结：当前阶段、今天完成了什么、明天第一步。
