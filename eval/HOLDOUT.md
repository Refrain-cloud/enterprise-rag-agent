## 运行规则

1. **只跑一次**：留出集和同义改写集各运行一次生成 + 判分（`--judge-repeats 1`），不因结果好坏重跑或改题。
2. **不回头调参**：看到结果后不得据此修改检索、提示词、路由、guard 或题目；若结果不理想，保留真实分数并解释差异。
3. **技术失败可重跑**：仅当出现 API 错误、进程中断等非模型质量原因导致题目缺失时，才允许用相同题目文件重跑；重跑原因写入结果说明。
4. **不并入默认基线**：结果以具名文件保存，不覆盖 `report.*` / `results.jsonl`。
5. **judge 稳定性复用已存回答**：用 `results_m3.jsonl` 的 20 题分层样本重复判分 3 次，不重新生成。
